# Test File Template

Test files generated by DOCUMENT (Section 3.5, TDD-first) carry an immutability marker. Format:

## TypeScript test file template

```typescript
/**
 * @test-contract
 * @feature: <feature-name>
 * @task: T-NN
 * @must-haves: ["truth 1", "truth 2", "truth 3"]
 * @sha256: <64-char hex hash of file content excluding this line>
 * @locked-at: <ISO 8601 timestamp>
 *
 * IMMUTABILITY: This file is locked. BUILD agents MUST NOT modify it.
 * Override protocol: see references/test-immutability-protocol.md.
 */

import { describe, it, expect } from 'vitest';
// import { ... } — agent fills in production imports during BUILD

describe('T-NN — <task title>', () => {
  it('<must-have 1>', () => {
    // BUILD agent implements production code that satisfies this assertion
    expect(/* TBD */).toBe(/* expected */);
  });

  it('<must-have 2>', () => {
    expect(/* TBD */).toBe(/* expected */);
  });

  // Additional must-have tests follow.
});
```

## Frontmatter field semantics

| Field | Type | Source |
|-------|------|--------|
| `@test-contract` | marker | always present; signals to verify-test-immutability that this file is hashable |
| `@feature` | string | feature directory name (matches `<feature>/.dev/MANIFEST.md`'s metadata) |
| `@task` | string `T-NN` | task ID from `<feature>/tasks/T-NN.md` |
| `@must-haves` | JSON-array of strings | verbatim quote of each truth from `<feature>/waves/WAVE_NN.md` `## must_haves` block for this task |
| `@sha256` | 64-char hex | SHA256 of file content with this `@sha256` line stripped |
| `@locked-at` | ISO 8601 timestamp | when DOCUMENT generated/regenerated this file |

## DOCUMENT generates this template

DOCUMENT Section 3.5 (Test Authoring) emits a file matching this template per task. The `@sha256` is computed last (after the rest of the content is finalized). Re-running DOCUMENT for a task regenerates the file.

## BUILD reads but does NOT modify

BUILD Layer 0 verifies the hash. BUILD agents implement production code that makes the test pass — they do NOT edit the test file. Edit attempts trigger the override protocol (see `test-immutability-protocol.md`).
